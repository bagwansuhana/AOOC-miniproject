# 🚤 Boat Booking System

A Java-based desktop application for managing boat bookings with a user-friendly graphical interface.

## ✨ Features

* User Login
* User Dashboard
* Boat Booking Management
* User Account Management
* Booking Data Storage
* Admin Dashboard
* Revenue Visualization

## 🛠️ Technologies Used

* Java
* Java Swing
* Object-Oriented Programming

## ▶️ How to Run

1. Clone the repository.
2. Open the project in a Java IDE.
3. Make sure Java JDK is installed.
4. Run `Main.java`.

## 📌 Project

This project was developed as an academic project to demonstrate Java GUI development and application-based programming.
